V3D Setup

Windows neu aufsetzen: Programme, Treiber, Updates

So geht's

1 · Alter Rechner
Starter laden und ausführen → 1) Inventar senden und 2) Treiber sichern. Die Programmliste erscheint hier unten.
2 · Hier abhaken
Links ankreuzen, was auf den neuen Rechner soll. Dann Auf V3DA herunterladen – die Installer liegen danach im Depot.
3 · Neuer Rechner
Nach der Windows-Installation denselben Starter ausführen → 3) Alles: Treiber zurück, Programme silent, Updates bis nichts mehr kommt.
