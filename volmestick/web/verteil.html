VolmeStick V3D

Windows- und Linux-Medien bauen – USB-Stick oder ISO für VMware.

Warum diese Seite

Ein USB-Stick lässt sich nur an dem Rechner beschreiben, an dem er auch steckt. VolmeStick arbeitet deshalb ausschließlich für den Rechner, auf dem es läuft – dieser Server hier verteilt es nur und speichert selbst keine Abbilder.

Zwei Minuten Einrichtung, danach läuft alles bei dir: Abbild herunterladen, Stick schreiben, Windows-Anpassungen setzen.

Auf dem eigenen Rechner starten

VolmeStick herunterladen (ZIP) – enthält alles, läuft unter Windows und Linux.

Windows

  1. ZIP entpacken (Rechtsklick → Alle extrahieren)
  2. windows\Weboberflaeche-starten.bat doppelklicken
  3. Nachfrage nach Administratorrechten bestätigen – ohne die darf Windows keinen Datenträger neu aufteilen
  4. Der Browser öffnet sich mit derselben Oberfläche – nur eben mit deinen USB-Sticks

Voraussetzung: Python von python.org, beim Installieren „Add python.exe to PATH“ ankreuzen. Wer lieber eine fertige EXE möchte: windows\EXE-bauen.bat baut sie einmalig.

Linux

  1. unzip VolmeStick-fuer-Windows.zip && cd VolmeStick
  2. sudo python3 server.py --browser

Schnellweg: Antwort-ISO für VMware

Möchtest du lieber eine einzige fertige ISO, die du in VMware einfach einbindest? Dann VolmeStick oben auf dem eigenen Rechner starten und dort „ISO bauen“ wählen – die Antworten werden in eine Kopie der Windows-ISO eingehängt. Das geht nur lokal, weil die ISO dabei durch den Rechner läuft.

Der Weg hier braucht dagegen gar keine Installation: Windows Setup sucht die autounattend.xml auf jedem Laufwerk – es genügt also, neben der Original-ISO ein zweites CD-Laufwerk mit dieser winzigen ISO einzuhängen. Die Original-ISO bleibt unangetastet.
