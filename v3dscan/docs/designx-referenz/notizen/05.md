## Funktionen

### 1. **Mesh Sketch per Kontextmenü** auf Fläche/Ebene
- **Ort:** Rechtsklick auf Körperfläche oder Ebene im Viewport › **Mesh Sketch** (Kontextmenü nicht
  im Bild).
- **Zweck:** Abkürzung statt SKETCH › Mesh Sketch + Ebene wählen.
- **Bedienablauf (00:05–00:49, 02:36–02:57):**
  1. Optional Netz ausblenden („as a shortcut you can hide the mesh“ – welcher Kurzweg, nicht gezeigt).
  2. Zeiger über Fläche, Rechtsklick › Mesh Sketch → öffnet direkt Mesh Sketch Setup mit dieser
     Fläche als Base Plane („Face 1“).
  3. **Offset** einstellen (Beispiel 1,5 mm), Bereich mit den Rand-Anfassern der Schnittebene
     **verkleinern** („I don't need this side … drag it in here“) → OK.
- **Dialog „Mesh Sketch Setup“** (`bild_0050`): wie Folge 04 – Target 1_Basic_Part, ● Planar Method,
  Base Plane „Face 1“, Section Polyline „Offset Section 1“, **Offset Distance From Base Plane 1.5 mm**,
  Silhouette Range 0 mm, Options Draft Angle 1° / Exclude Round Corner 5 mm / Avg. Section.
- **Bildbeobachtung:** Schnittebene als **hellblau-transparentes Rechteck** mit blauen Eckpunkten,
  grünen Punkten, gelber Kante und **orangem Doppelpfeil** zum Ziehen der Begrenzung; Versatz-Wert
  „1.5 mm“ direkt am Pfeil.
- **Zeitmarken:** 00:05–00:49, 02:36–02:57 · **Bild:** `bild_0050`
- **Status V3D Scan:** **✗** (Etappe 4; Kontextmenü am Viewport fehlt generell).

### 2. **Circle (Fit Polyline) + Equal-Constraint + Smart Dimension** (Design Intent)
- **Ort:** SKETCH › Draw › Circle; Constraints; Smart Dimension.
- **Ablauf (00:49–01:34, 02:57–03:18):**

  2. Beide Kreise wählen › Constraints › **Equal Radius**.
  3. Maß setzen: gemessen **9,87** → auf **10 mm** ändern („Hence adding my condition“).
- **Dialog „Circle“** (`bild_0305`): Center X/Y (z. B. −137,3 / 40 mm) · Radius (0 mm grau) ·

- **Kontextmenü am Objekt als Abkürzung:** Rechtsklick auf Fläche → Mesh Sketch; Rechtsklick auf
  Körper im Model-Baum → Export; Rechtsklick auf Feature → Edit (Folge 04).
- **Dialog-Kopf** wie in Folge 04 (▼ Titel · Schloss · ✓ · ✗); kontextabhängige Unteroptionen
  erscheinen erst bei passender Wahl (Merge → All Bodies / Selected Bodies).
- **Anfitten statt Zeichnen** auch für Kreise und Rechtecke (Drag-Box über Polylinie).
- **Design Intent:** Messwert 9,87 → Nennmaß 10 per Smart Dimension; Gleichheit per Equal Radius.
- **Endkörper heißt wie das letzte Feature** („Extrude5 (Cut)“) – Name taucht im Export-Dialog auf.
- **Fortsetzbarer Transfer:** langer, schrittweiser Vorgang mit Wiederaufnahme ab gewähltem Feature,
  Pause-Punkt und Abschlussmeldung.
- **Farben:** Auswahl im Baum/Viewport rot-rosa hervorgehoben (`bild_0350`, `bild_0520`); markierte
  Ebene türkis (`bild_0828`).

## Was für V3D Scan am wertvollsten ist

1. **Export des Körpers als STEP (Rechtsklick › Export)** – kleinster Schritt mit größter Wirkung: ohne
   ihn verlässt kein CAD-Ergebnis unsere App. OCP kann STEP/IGES schreiben (unter Wine belegt).
2. **Übergabe mit Verlauf an V3D CAD als eigener „LiveTransfer“** – der Kern der Folge: nicht nur
   Geometrie, sondern Skizzen + Maße + Features (Extrude/Revolve/Fillet mit Namen) übertragen. Für uns
   machbar, weil beide Seiten eigener Code sind: Feature-Liste als JSON (Skizze, Methode, Operator,
   Werte) statt Fernsteuerung eines Fremd-CAD. Optionen „Start From First Feature / Resume From
   Selected Feature / Only Selected Entities“ und „Prefix For Feature Name“ als Vorbild.
3. **Mesh Sketch per Rechtsklick auf Fläche + Bereich eingrenzen** – spart pro Feature mehrere
   Klicks; passt in Etappe 4 direkt mit hinein.
4. **Extrude-Methoden Up To Surface und Mid Plane mit Merge/Cut** – reichen zusammen mit Folge 04 für
   das ganze prismatische Teil.
5. **Rollback-Leiste im Feature-Baum** – Nachvollziehbarkeit „vom Scan zum CAD“; erst sinnvoll, wenn
   der Feature-Baum existiert.
