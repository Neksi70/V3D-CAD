# 08 Point Cloud Data | Geomagic Design X Go Training

**Dauer:** ca. 35 min (letzte Zeitmarke 34:42) · **Quelle:** YouTube-Kanal Geomagic (lErmchuWerY) ·
**Material:** `videos/08/text.txt` (Auto-Untertitel), Standbilder `videos/08/bild_MMSS.jpg` ·
**Programmversion laut Titelleiste:** „Geomagic Design X 2025.1.0 [Go]“

Hands-on-Übung mit sechs Punktwolken (`Scan-01.asc` … `Scan-06.asc`) eines Hebels, die einzeln und
gegeneinander verschoben im Raum liegen. Gezeigt wird der komplette Weg **Punktwolke → Netz**:
Import mehrerer Wolken mit Abtastrate, paarweises Ausrichten mit **Align Between Scan Data** (drei
Methoden: Auto Guess, Picked Point, Global and Fine), **Combine** mit Überlappungsentfernung,
schrittweises Anhängen weiterer Scans, **Filter Noise**, **Sampling**, ein kurzer Ausflug „Reverse
Engineering direkt auf der Punktwolke“ (Best-Fit-Ebene + Mesh Sketch) und schließlich
**Triangulate** (Mesh Construction / HD Mesh Construction) mit anschließendem **Fill Holes** und
Säubern per **Flood**-Auswahl. Sprecher-Fazit: Reverse Engineering geht auch auf Punkten, auf dem Netz
ist es aber bequemer.

## Funktionen

### 1. **Import** (mehrere Punktwolken, Sampling Ratio)
- **Ort:** HOME › File › **Import**.
- **Zweck:** mehrere Punktwolken auf einmal laden, bei großen Daten schon beim Import ausdünnen.
- **Ablauf:** 1. Import · 2. Ordner „E1“ · 3. erste Datei klicken, **Shift** + letzte Datei → alle sechs
  `.asc` gewählt · 4. Optionen setzen · 5. **Import Only**.
- **Dialog-Parameter (sichtbar):** ☐ Fix Erroneous Data · ☐ Use ASCII Convert · ☐ Import Hidden Bodies
  (grau) · ☑ **Use Custom Setting** · ☑ Points Only (grau) · ☐ Suppress Mesh (grau) · ☑ **Include Vertex
  Normal** (Sprecher: „please leave it on“) · ☐ **Combine Point Clouds** · **Unit** mm · **Precision**
  Float · **Include Texture** None · **Sampling Ratio 1/1** (laut Sprecher auch 1/4, 1/9, 1/16 für sehr
  große Wolken, z. B. Raumscans) · Triangulation Cutoff Angle 75 (grau).
- **Ergebnis:** im **Model-Baum** Gruppe *Point Clouds* mit Scan-03, -04, -05, -06, -01, -02, **jede
  Wolke in eigener Farbe**; im Feature-Baum erscheinen sie **nicht** (Sprecher + `bild_0305.jpg`).
- **Zeitmarken:** 00:45–02:53 · **Bilder:** `bild_0135.jpg`, `bild_0305.jpg`
- **Status V3D Scan:** Punktdaten-Import **✔** (ply/pcd/xyz/pts/asc/csv); Abtastrate beim Import und
  „Combine Point Clouds“ beim Import im Abgleich nicht aufgeführt (vermutet ✗).

### 4. **Align Between Scan Data** – Methode *Local Based On Picked Point*
- **Ort:** wie oben, Radioknopf *Local Based On Picked Point*.
- **Zweck:** Grobausrichtung über von Hand gesetzte Punktpaare.
- **Dialog:** **Reference** (Tooltip „Point Cloud, Mesh“; beim Klick gelber Rahmen) · **Moving** ·
  ☑ **Refine Alignment** (nach den Paaren automatisch feiner).
- **Ablauf:**
  1. Nur Reference- und Moving-Scan sichtbar lassen; Reference = Scan-01 („bewegt sich nicht“), Moving
     = Scan-03.
  2. Ansicht **teilt sich**: rechts oben *Reference*, rechts unten *Moving* (je eigene Ansicht, eigener
     Maßstab), links die gemeinsame **Vorschau**. Beide Teilansichten ähnlich drehen; Tipp: „align to
     normal“-Ansicht.
  3. Punkt im Reference anklicken (rote Kugel), dann dieselbe Stelle im Moving – schon nach **einem**
     Paar springt die Vorschau links. Weitere Paare: 2. grün, 3. blau, dann gelb, magenta …
  4. **Mindestens 3** Punkte, **nicht in einer Ebene**; empfohlen „eight points“; ungenau reicht
     („you don't need to be very accurate“). Nur Stellen wählen, die in **beiden** Scans Daten haben.
  5. Falsch geklickt → **Ctrl+Z** nimmt den letzten Punkt zurück.
  6. Häkchen an *Method* (wendet Refine Alignment an) **und** Häkchen oben im Dialogkopf – Sprecher:
     „there are two check boxes“.
- **Ergebnis:** Moving liegt grob auf Reference; danach Global And Fine.
- **Zeitmarken:** 06:25–12:13, 16:46–19:12 · **Bilder:** `bild_0650.jpg` (geteilte Ansicht, Felder),
  `bild_0905.jpg` (Reference Scan-01 / Moving Scan-03, erste rote Punkte), `bild_1120.jpg` (5 farbige
  Paare, Vorschau links)
- **Status V3D Scan:** **✔** („2 · Manuell mit Punktpaaren“: abwechselnd fest/bewegt klicken, ≥ 3 Paare,
  „Letzten Punkt weg“, ☑ danach ICP). Unterschied: bei uns keine geteilte Ansicht und keine
  Live-Vorschau nach jedem Paar (erst „Berechnen“).

## Querliegende Bedien-Muster

- **Dialogkopf** wie in Folge 06: Schloss, Lupe (Vorschau), ✓, ✗; im Vorschau-Zustand wird der Dialog
  grau und zeigt ✓ + ↶ (zurück) (`bild_3019`, `bild_3125`). **Zwei Bestätigungsebenen**: Häkchen am
  Abschnitt *Method* (Zwischenergebnis anwenden) und Häkchen im Dialogkopf (abschließen).
- **Rollen-Felder Reference / Moving**: Klick ins Feld (gelber Rahmen), dann Objekt im Model-Baum,
  Viewport oder in den **Entity Thumbnails** wählen; Reference bleibt fest. „Mehr Daten = Reference“.
- **Geteilte Ansicht** beim Paaren: Reference oben rechts, Moving unten rechts, Ergebnis-Vorschau links;
  Punktpaare in **gleichen Farben** (rot, grün, blau, gelb, magenta …) in beiden Ansichten.
- **Schieber mit Wortenden** statt Zahlen: Speed↔Quality, Loose↔Tight, Weak↔Strong, Less↔More,
  SD/HD/UHD.
- **Auto-Werte** mit Rechen-Symbol: Sampling Ratio „Auto“, Max. Average Deviation „Auto“ → Programm
  setzt konkreten Wert (0.0169 mm).
- **Gekoppelte Felder**: Zielanzahl ↔ Prozent (Sampling).
- **Tastenkürzel:** Shift-Klick (Dateibereich), Ctrl+A (alle), Ctrl+Z (letzten Punkt zurück),
  Ctrl+Klick (aus Auswahl nehmen), Entf (löschen); Aufziehrahmen zum Wählen.
- **Farben:** jede Wolke eigene Farbe; Auswahl türkis; Box-Filter türkis mit blauen Griffen; Lochrand
  orange-braun.
- **Baum-Logik:** Punktwolken und ihre Bearbeitung (Ausrichten, Combine, Filter, Sampling) erscheinen
  nur im **Model-Baum**, nicht im Feature-Baum; das Netz aus Triangulate dagegen schon (abschaltbar
  über „Suppress Result In Feature Tree“).
- **Automatisches Speichern** fragt per Hinweis unten rechts „Automatic Save – Do you want to save the
  model now?“ (Save / Cancel / Set) (`bild_3005.jpg`).

## Was für V3D Scan am wertvollsten ist

Die Punktwolken-Strecke ist bei uns schon weitgehend **✔** – die Lücken liegen in der Bedienung:

1. **Geteilte Ansicht beim Punktpaar-Ausrichten mit Live-Vorschau nach jedem Paar** und gleichfarbigen
   Markern: macht unser vorhandenes „Manuell mit Punktpaaren“ deutlich leichter (heute: in einer
   Ansicht abwechselnd klicken, dann „Berechnen“). Reiner UI-Umbau, die Mathematik (Kabsch + ICP) ist
   da.
2. **Combine mit echtem „Remove Overlap Region“**: unser Zusammenführen dünnt nur per Voxel aus;
   Überlappung gezielt entfernen verhindert Doppelschichten, die beim Vernetzen stören.
3. **Sampling nach Zielanzahl/Prozent und mit Consider Curvature**: Kanten und Radien bleiben scharf,
   flache Bereiche werden dünn – wichtig für spätere Formerkennung und Mesh Sketch.
4. **Box-Volumen-Filter mit Anfassern** (drehbar) und **Flood-Auswahl + Inverse**: schnell gegen
   Tisch-/Halterreste; ergänzt unsere statistischen Filter um ein sichtbares, direkt steuerbares Werkzeug.
5. **Abbruchkriterium „Max. Average Deviation (Auto)“ + „Apply Only Small Transform“** bei der
   Feinausrichtung und mehrere Moving-Scans in einem Lauf: stabilere Ergebnisse bei vielen Teilscans.
   Abtastrate schon beim Import (1/4, 1/9, 1/16) ist für sehr große Wolken ein günstiger Zusatz.
