# 09 Advanced Lofted Surfaces | Geomagic Design X Go Training

**Dauer:** ca. 41–42 min (letzte Zeitmarke 41:16) · **Quelle:** YouTube-Kanal Geomagic (lQQaSgtID88) ·
**Material:** `videos/09/text.txt` (Auto-Untertitel), Standbilder `videos/09/bild_MMSS.jpg` ·
**Programmstand im Bild:** „Geomagic Design X 2025.1.0 [Go] [Not for Resale]“ (Titelleiste)

Hands-on-Folge am Scan eines **beschädigten Lüfterrads** (`fanblade.stl`, 5 Schaufeln, teils
korrodiert). Teil 1: das rotationssymmetrische Gehäuse über **Vector (Revolving Axis) → Plane (Pick
Point & Coplanar Axis) → Mesh Sketch im Rotational Method → Revolve** nachbauen. Teil 2: eine gute
Schaufel isolieren (**View Clip** oder **Mesh kopieren + Polygone löschen**), mit **Plane Draw Line +
Offset (Number)** sieben parallele Schnittebenen legen, auf jeder eine Mesh Sketch nachzeichnen und
daraus eine **Loft-Fläche** (Create Surface) bilden. Zwei begrenzende **Extrude-Flächen** (Mid Plane)
kommen dazu. Weil Go **kein Extend/Trim für Flächen** hat, wird der Rest per **LiveTransfer** in
SOLIDWORKS fertig gemacht (Extend Surface, Trim, Offset, Thicken, Circular Pattern, Combine).

**Hinweis zum Bild:** Der rosa Punkt neben dem Mauszeiger ist in allen Bildern zu sehen, auch in
SOLIDWORKS – vermutet: Klick-Anzeige der Bildschirmaufnahme, kein Programmelement.

### 10. **Skizzen-Nachzeichnen: Fit per Doppelklick, 3 Points Arc, Tangent Arc, Fillet, Trim**
- **Ort:** SKETCH › Draw / Tools.
- **Bedienablauf:**
  1. **Centerline** mit beiden Punkten auf dem Vektor (Drehachse fürs Revolve).
  2. **3 Points Arc**: über die Schnittlinie fahren (wird **gelb**), **Doppelklick** = Best-Fit-Bogen
     auf das Segment.
  3. **Tangent Arc**: am Endpunkt (Vertex) ansetzen, gedrückt halten und auf die Spur ziehen;
     **grünes Tangenz-Symbol** zeigt Tangentialität an. Beliebig oft aneinanderhängen.
  4. **Line**: Segment überfahren (gelb) → Doppelklick = Best-Fit-Linie.
  5. **Trim › Corner Trim**: zwei Elemente anklicken → Ecke geschlossen.
  6. **Fillet** (Skizze): Bogen anklicken, auf Linie gedrückt halten, auf die Spur ziehen.
  7. Kurven/Punkte jederzeit **ziehen**, um die Abweichung zu verringern.
- **Dialoge:** Tangent Arc (`bild_0820.jpg`): Center X/Y · Radius · Start X/Y · End X/Y · For
  Construction ☐. 3 Points Arc (`bild_3520.jpg`): Center · Radius · Start · End · For Construction ☐
  · **Fit Polyline ☑**. Trim (`bild_0950.jpg`): ○ Power Trim / ● Corner Trim. Fillet
  (`bild_1035.jpg`): Specify Value ☐ · Add Dimension ☑.
- **Ergebnis:** Linien blau, Spur magenta, grüne Constraint-Symbole an Elementen.
- **Zeitmarken:** 07:42–11:11, 22:02–26:17 · **Bild:** `bild_0820.jpg`, `bild_0905.jpg`,

## Querliegende Bedien-Muster

- **Dialog-Kopf:** dunkles, halbtransparentes Panel links oben im Viewport; Titel mit ▼; rechts im
  Kopf Symbole **Vorschau (Lupe)**, **✓ OK**, **✕ Abbrechen**; bei Plane/Vector zusätzlich
  Schloss-Symbol am Method-Feld (`bild_0520`, `bild_1935`). Abschnitte einklappbar (▼/▶).
- **Vorauswahl wird übernommen:** vor dem Befehl gewählte Polygone landen direkt im Entities-Feld
  (Vector, Plane).
- **Aktives Eingabefeld gelb umrandet** (Entities, Target, Profiles); Tooltip listet zulässige
  Entity-Typen.
- **Live-Vorschau** bei Plane, Mesh Sketch, Revolve, Loft, Extrude; Viewport-Griffe: blaue Pfeile
  (Versatz), Drehringe (rot/grün/gelb), Eckgriffe an Ebenen/Box.
- **Skizzenmodus:** Ribbon wechselt auf SKETCH, Skizze rot im Baum; schwebende Exit/✕-Knöpfe unten
  rechts; Hover über Spur = **gelb**, Doppelklick = Best-Fit.
- **Tastenkürzel/Maus:** Shift = Auswahl hinzufügen; Ctrl+C/Ctrl+V = Mesh kopieren; Entf = Polygone
  löschen; Rechtsklick auf Ebene = Mesh Sketch; Rechtsklick auf Auswahl = Inverse Poly-Faces.
- **Auswahlmodi** in der Leiste oben: Visible Only ↔ Select Through; Rectangle; Smart Selector;
  „Line selector mode“ (Sprecher) für Baum-/Element-Picken.
- **Farben:** Netz hellblau; Auswahl türkis; gewähltes Mesh magenta; Schnittspur magenta;
  Skizzenelemente blau; Hover gelb; Constraint-Symbole grün; Vorschau-Fläche orange; Abweichung
  Rot–Grün–Blau, grünes Toleranzband.
- **Bäume:** Feature-Baum (Verlauf) oben, Model-Baum nach Typ unten mit Augen-/Kästchen-Spalte;
  neue Typgruppen erscheinen erst bei Bedarf (Reference Vectors, Solid Bodies, Surface Bodies).
- **Umbenennen** im Feature-Baum (Vector1 → Revolve_Axis).

## Was ist für V3D Scan am wertvollsten nachzubauen?

1. **Ebenen-Werkzeugkasten (Offset mit Number, Draw Line, Pick Multiple Points, Pick Point &
   Coplanar Axis) + Vector Revolving Axis.** Ohne dauerhafte Referenzgeometrie im Baum gibt es keine
   Mesh-Skizze. „Offset × Number“ ist der Schlüssel für Querschnittsreihen; Revolving Axis lässt sich
   aus unserer vorhandenen Zylinder-/Rotationserkennung ableiten.
2. **Mesh Sketch Planar + Rotational + Silhouette Range.** Rotational ist für Drehteile (häufig bei
   Ersatzteilen) der kürzeste Weg zum Profil; Silhouette löst das Problem lückenhafter Einzelschnitte.
3. **Doppelklick-Best-Fit für Linie/Bogen + Tangent Arc + Corner Trim + Disjoined Ends.** Das ist
   der eigentliche Zeitgewinn beim Nachzeichnen; Disjoined Ends verhindert offene Profile vor dem
   Extrudieren.
4. **View Clip (Below Plane / Between Two Planes / Inside Box).** Billig in three.js (Clipping
   Planes), großer Nutzen bei Teilen mit verdeckten Bereichen.
5. **Loft-Fläche aus Profilen mit Startpunkt-Kugel** (OCP `BRepOffsetAPI_ThruSections`) – erst nach
   1–3 sinnvoll. Extend/Trim, die Go fehlen, sollten wir direkt mit anbieten (OCP kann es), damit
   kein externes CAD nötig ist – das wäre ein echter Vorteil gegenüber Go.
