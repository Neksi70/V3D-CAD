# 03 Extracting Reference Geometry & Mesh Sketching | Geomagic Design X Go Training

· **Programmstand im Bild:** Geomagic Design X 2025.1.0 [Go]

Fortsetzung mit demselben Teil `1_Basic_Part`. Ziel: das Teil als Extrusion neu aufbauen. Gezeigt
wird der **Kern-Arbeitsablauf Scan → CAD in Go**: (1) Referenz-**Ebenen** aus ausgewählten
Dreiecken fitten (Best Fit / Min. Bound / Max. Bound, Ausreißerfilter, Richtungs-Zwang),
(2) Referenz-**Vektoren** als Zylinder-/Kegelachse fitten und nachträglich senkrecht zur Basisebene
zwingen, (3) **Mesh Sketch**: Schnitt der Basisebene mit Versatz durch das Netz → pinke
Schnittpolylinie, (4) darauf **Linien/Bögen/Kreise per Doppelklick fitten**, (5) Zwangsbedingungen,
offene Enden finden (**Disjoined Ends**), **Corner Trim**, **Smart Dimension** mit Rundung auf
Nennmaß, Mittellinie bis „voll bestimmt“, (6) Sketch verlassen → Extrude wird verfügbar (Extrude
selbst nur angerissen, folgt in Folge 04). F1 öffnet zu jedem Werkzeug die Hilfe.

### 4. **Plane** (Add Plane) – Methode **Extract**, Fitting Type **Best Fit**
- **Ort:** MODEL › Reference Geometry › **Plane** (auch HOME › Reference Geometry › Plane).
- **Zweck:** Referenzebene durch ausgewählte Scan-Dreiecke fitten – Grundlage für Skizzenebene.
- **Bedienablauf:**
  1. Plane klicken → schwebendes Werkzeugfenster **Add Plane** links oben im Viewport.
  2. Feld **Entities** ist **gelb umrandet** = wartet auf Eingabe.
  3. **Method** von „Definition“ auf **Extract** stellen.
  4. Dreiecke wählen: Rectangle-Modus, mit **Shift** mehrere Rahmen auf die Oberseite (Bild:
     große türkise Fläche). Feld zeigt dann „Poly-Faces of 1_Basic_Part“.
  5. **Preview** (Lupe im Fensterkopf) → Ebene erscheint **orange**, gewählte Punkte türkis.
  6. **Accept** (✓) → Ebene angelegt; Werkzeug bleibt offen, mit **Cancel** (✕) verlassen.
  - **Variante Vorauswahl** (07:49): erst mit Smart Selector die Oberseite wählen, dann Plane
    öffnen – Entities ist schon gefüllt, Method Extract/Best Fit, OK.
- **Dialog Add Plane (`bild_0435.jpg`, `bild_0605.jpg`, `bild_0650.jpg`):**
  - Kopf: Schloss-Symbol · **Preview** (Lupe) · **OK** (✓) · **Cancel** (✕). Nach Preview wird der
    Dialog grau, Kopf zeigt ✓ und **Restore** (↶ zurück in die Bearbeitung) (`bild_1035.jpg`).
  - **Entities** · **Method** (Standard **Definition**): Definition, Extract, Projection, Pick
    Multiple Points, Pick Point & Normal Axis, Pick Point & Coplanar Axis, Convert, N Division,
    Offset, Rotation, Average, View Direction, Tangent, Orthogonal, Draw Line, Mirror, Extreme
    Position. Bei „Definition“: Input Options › Input „Position …“, Position X/Y/Z, Normal X/Y/Z.
  - **Fitting Options:** Fitting Type **Best Fit** | Min. Bound | Max. Bound · **Remove Outlier ☑**
    Methode **N * Sigma**, Wert **3** (Sprecher: außerdem „filter with ratio“ und „filter with
    distance“) · Use Normal ☐ · Sampling Ratio **100 %** · Use Only Effective Data ☐.
  - **Constraint Options:** Axis Constraint ☐ · **More Options** (zugeklappt, nicht gezeigt).
- **Ergebnis:** **Plane1** im Feature-Baum und im Model-Baum unter Reference Planes, Ebene türkis
  umrandet mit Beschriftung „Plane1“. Properties (`bild_0735.jpg`): Name Plane1, Entity Type
  Reference Plane, Suppressed False, **Method Extract**, Visibility True, Position `-0.1271,
  -54.6456, -0.0527`, Normal `-0.001, -0.001, -1`. Zweite Ebene per Smart Selector → **Plane2**.
- **Zeitmarken:** 04:19–08:56 · **Bilder:** `bild_0435.jpg`, `bild_0605.jpg`, `bild_0650.jpg`,
  `bild_0735.jpg`
- **Status V3D Scan:** Referenzgeometrie **◐** (nur intern für 3-2-1, keine dauerhaften Elemente).

### 5. **Plane – Max. Bound / Min. Bound** (Ebene durch höchsten/tiefsten Punkt)
- **Zweck:** Ebene durch den obersten bzw. untersten Punkt der Auswahl (Beispiel: Scheitel der
  Halbkugel).
- **Bedienablauf:**
  1. Rectangle-Modus, **Visible Only aus** (Select Through), Rahmen um die Kugel.
  2. Plane öffnen (Vorauswahl übernommen), Fitting Type **Max. Bound** → Preview zeigt Ebene am
     Scheitel.
  3. Über **Restore** zurück, **Min. Bound** probieren → Preview am Fuß der Auswahl
     (`bild_1035.jpg`: Kugelpunkte türkis, Min. Bound gewählt).
  4. Zurück auf Max. Bound.
- **Zeitmarken:** 08:56–10:39 · **Bild:** `bild_1035.jpg`
- **Status V3D Scan:** **✗**.

### 6. **Axis Constraint** (Ebene/Vektor an eine Richtung binden)
- **Ort:** Add Plane / Add Vector › Constraint Options › **Axis Constraint ☑**.
- **Zweck:** Max.-Bound-Ebene soll **parallel zu Plane2** liegen; Vektor soll **senkrecht zu Plane1**
  stehen.
- **Bedienablauf:**
  1. Axis Constraint anhaken → Optionen klappen auf.
  2. Radio **Use Specified Direction As Initial Guess** oder **Use Specified Direction As It Is**
     (im Video: As It Is).
  3. Feld **Direction** (gelb = aktiv) → Plane2 im Viewport anklicken (Überfahren färbt rot) oder im
     Baum wählen.
  4. Preview / OK.
- **Dialog (`bild_1120.jpg`):** Direction · **User Defined** mit Knöpfen X / Y / Z und Umkehr-Pfeil,
  Felder X 0 · Y 0 · Z **1** (Standard).
- **Ergebnis:** **Plane3** (Max. Bound, parallel zu Plane2) im Baum.
- **Zeitmarken:** 10:39–12:05 · **Bild:** `bild_1120.jpg`

### 7. **Vector** (Add Vector) – **Find Cylinder Axis** / **Find Cone Axis**
- **Ort:** MODEL › Reference Geometry › **Vector** (neben Plane).
- **Zweck:** Achse einer Bohrung (Zylinder) bzw. Senkung/Kegel als Referenzvektor.
- **Bedienablauf (Zylinder):**
  1. Vector klicken → **Add Vector** (Standard-Methode **Definition** mit Input „Position &
     Direction“, Position X/Y/Z und Direction X/Y/Z, `bild_1250.jpg`).
  2. Method **Find Cylinder Axis**.
  3. **Smart Selector**: in die Bohrungswand klicken, ziehen bis die ganze Innenfläche türkis ist.
  4. Preview → Vektor **orange** → ✓.
  5. Eintrag umbenennen: anklicken bzw. Rechtsklick › Umbenennen → „Cylindrical_Vector“.
- **Bedienablauf (Kegel):** erst Innenfläche der Senkung mit Smart Selector wählen, dann Vector
  öffnen (Entities schon gefüllt) → Method **Find Cone Axis** → Preview → OK → umbenennen
  „Conical_Vector“.
- **Methoden laut Sprecher:** Extract, Find Slot Axis, Find Cylinder Axis, Find Cone Axis „etc.“
  (Liste nicht im Bild aufgeklappt).
- **Dialog (`bild_1335.jpg`, `bild_1401.jpg`):** Entities · Method · **Fitting Options:** Fitting
  Type Best Fit · Remove Outlier **☐**, N * Sigma **1.6** · Sampling Ratio 100 % · Use Only Effective
  Data (grau) · **Constraint Options:** **Fix Radius ☐** · Axis Constraint ☐ · More Options.
- **Ergebnis:** im Feature-Baum Cylindrical_Vector, Conical_Vector; im Model-Baum neuer Container
  **Reference Vectors**; Beschriftung am Vektor im Viewport (`bild_1447.jpg`).
- **Zeitmarken:** 12:30–15:25 · **Bilder:** `bild_1250.jpg`, `bild_1335.jpg`, `bild_1401.jpg`,
  `bild_1447.jpg`
- **Status V3D Scan:** Zylinder/Kegel werden erkannt (Merkmal-Deutung, „mehr als Go“), aber als

### 9. **Mesh Sketch** (Mesh Sketch Setup) – Kernfunktion
- **Ort:** Reiter **SKETCH** › Gruppe Setup › Knopf **Sketch** (Dropdown) › **Mesh Sketch**. Zweiter
  Eintrag **Sketch** = normale CAD-Skizze („Enter sketch mode“) (`bild_1850.jpg`).
- **Zweck:** Schnitt einer Ebene mit dem Netz als Pause für die 2D-Skizze.
- **Bedienablauf:**
  1. Mesh Sketch wählen → Fenster **Mesh Sketch Setup**; Target = `1_Basic_Part` (automatisch).
  2. **Planar Method** (Standard) lassen.
  3. **Base Plane**: Plane1 im Viewport anklicken (Überfahren färbt **rot**) oder im Baum wählen.
     Falsche Wahl: Eintrag im Feld anklicken + **Entf**.
  4. Es erscheint die **Schnittvorschau türkis** auf einer halbtransparenten türkisen Ebenenfläche
     mit farbigen Eck-/Kantengriffen (blau/rot/grün); Ebenenrechteck per Ziehen **vergrößern und
     verschieben**, bis das ganze Teil abgedeckt ist.
  5. **Dicker blauer Pfeil = Silhouette**, **dünner blauer Pfeil = Offset**. Offset-Pfeil ziehen →
     Schnitt wandert live mit, Wert am Pfeil („0 mm“; Sprecher zieht auf 27 mm, dann 3 mm).
  6. Oder Wert tippen: **Offset Distance From Base Plane = 2 mm** (Standard **0 mm** liefert bei der
     Auflagefläche einen unbrauchbaren Schnitt – „non useful information“).
  7. **✓** → Skizzenmodus öffnet sich.
- **Dialog (`bild_1935.jpg`, `bild_2105.jpg`, `bild_2150.jpg`):**
  - Kopf: Preview (Lupe) · ✓ · ✕.
  - **Target:** 1_Basic_Part · ◉ **Planar Method** / ○ **Rotational Method**.
  - **Base Plane:** Plane1.
  - **Add Section Polyline:** Section Polyline [**Offset Section 1** ▼] mit **+** (weiteren Schnitt
    hinzufügen) und Papierkorb · **Offset Distance From Base Plane** 0 mm (mit Umkehr-Pfeil und
    Zusatzknöpfen) · **Silhouette Range** 0 mm.
  - **Options:** Draft Angle ☐ 1° · Exclude Round Corner ☐ 5 mm · Avg. Section (grau).
  - Properties zeigt während des Setups „Offset Section 1“.
- **Ergebnis:** Skizzenmodus; Schnitt als **pinke Polylinie** auf die Skizzenebene projiziert
  („This is what we call a polyline“). Nach Verlassen: **Sketch1 (Mesh)** im Feature-Baum, im
  Model-Baum Container **Sketches**; Properties: Entity Type Sketch, **Parent Mesh 1_Basic_Part**,
  Bounding Box `99.6958, 200.5934, 0.2799`.
- **Zeitmarken:** 18:15–23:29 · **Bilder:** `bild_1850.jpg`, `bild_1935.jpg`, `bild_2105.jpg`,
  `bild_2150.jpg`, `bild_2235.jpg`
- **Status V3D Scan:** **✗** (Etappe 4 – Herzstück).

### 11. **Line** mit **Fit Polyline** (Linie per Doppelklick an Spur fitten)
- **Ort:** SKETCH › Draw › **Line**.
- **Bedienablauf:**
  1. Line wählen → Spur wird eingefärbt: **durchgezogen pink = als Gerade erkannt**, **gepunktet

### 13. **Constraints** (Zwangsbedingungen) – Rechtsklick und Dialog
- **Rechtsklick auf ein Element (`bild_2835.jpg`):** Mini-Symbolleiste über dem Menü mit

- **Symbole:** angebrachte Bedingungen als **grüne Kästchen** an der Linie; Überfahren → **rot**;

- **Mehrere Elemente:** erstes anklicken (türkis), mit **Ctrl oder Shift** weitere → SKETCH ›

- **Properties einer Linie:** Name „Curve 2“, Entity Type Curve, Feature Sketch1 (Mesh), Type Line,

### 14. **Disjoined Ends** (offene Enden finden) im Accuracy Analyzer
- **Ort:** rechte Spalte › Reiter **Accuracy Analyzer(TM)** (im Skizzenmodus).
- **Zweck:** Profil muss geschlossen sein, damit es extrudierbar ist; offene Enden sichtbar machen.
- **Bedienablauf:** Reiter öffnen › **Disjoined Ends ☑** → nicht verbundene Endpunkte **grün**
  markiert.
- **Dialog (`bild_3435.jpg`):** Type ◉ None / ○ Deviation / ○ Curvature + ☑ Disjoined Ends ·
  Deviation Option (Max. Dist. 50 mm, Max. Angle 45 – grau) · Tolerance Color · Vector Resolution
  (Low–High) · Vector Multiplier (Value 1, Auto) · Adjust Colorbar Range.
- **Ansatz 1 (nicht empfohlen):** Endpunkt ziehen und auf den anderen fallen lassen
  (Coincidence-Symbol erscheint) – ändert die Linienrichtung; mit Undo zurück.
- **Zeitmarken:** 32:41–34:26 · **Bild:** `bild_3435.jpg`
- **Status V3D Scan:** Accuracy Analyzer **◐** (nur Netz↔Netz); für Skizzen **✗**.

### 15. **Trim** – **Corner Trim** (Ecke schließen ohne Richtungsänderung)
- **Ort:** SKETCH › Tools › **Trim** → Fenster Trim mit ○ **Power Trim** / ◉ **Corner Trim**.
- **Zweck:** Power Trim = Überstehendes wegschneiden; Corner Trim = zwei Elemente bis zum Schnittpunkt
  verlängern/kürzen und verbinden.
- **Bedienablauf:**
  1. Corner Trim wählen.
  2. Element 1 anklicken, mit der Maus über Element 2 fahren → **gelbe Vorschau** der neuen Ecke.
  3. Passt es: Klick → grüne Markierung verschwindet, Ecke verbunden (Linie **dunkelblau**).
  4. Für alle Ecken (Linie–Linie, Linie–Bogen) wiederholen; Esc beendet.
- **Zeitmarken:** 34:26–37:42 · **Bild:** `bild_3520.jpg`
- **Status V3D Scan:** **✗** (Etappe 4).

## Bedien-Muster (quer)

- **Schwebendes Werkzeugfenster** links oben im Viewport für jeden Befehl (Add Plane, Add Vector,
  Mesh Sketch Setup, Line, Constraints, Trim, Smart Dimension): Titel + Kopfknöpfe **Lupe =
  Preview**, **✓ = OK/Accept**, **✕ = Cancel**; Abschnitte auf-/zuklappbar (▼/▶), seltene Optionen
  unter **More Options**. Beim Bearbeiten heißt das Fenster „… Property“.
- **Vorschau-Zyklus:** Preview → Ergebnis **orange**, Dialog ausgegraut → ✓ übernehmen oder
  **Restore** zurück zur Bearbeitung.
- **Aktives Eingabefeld gelb umrandet** (Entities, Direction, Section Polyline); Feld anklicken +
  Entf löscht die Wahl. Pick im Viewport oder im Baum gleichwertig.
- **Vorauswahl:** Dreiecke vor dem Befehl auswählen → Entities automatisch gefüllt.
- **Werkzeug bleibt nach ✓ offen** für das nächste Element; Verlassen mit ✕ bzw. **Esc**.
- **Rechtsklick im Baum** → Edit, Umbenennen; Rechtsklick im Viewport → Mini-Symbolleiste +
  Auswahlmenü (Shift+A / Shift+N / Shift+I).
- **F1** auf jedem Werkzeug → Handbuchseite im Reiter Help.
- **Mehrfachauswahl** Ctrl oder Shift; **Doppelklick** = fitten (Skizze) bzw. Maß bearbeiten.
- **Farben:** Netz hellblau · Auswahl/aktuelles Element **türkis** · Vorschau **orange** · Überfahren
  zum Picken **rot** · Schnittspur **pink** (durchgezogen = Gerade, gepunktet = Bogen) · Hover/
  Vorschau im Skizzenmodus **gelb** · Skizzenelemente **blau**, voll bestimmt **schwarz** ·

- **Kontextabhängig grau:** Extrude & Co. erst nach einer Skizze; Tooltip sagt warum.

## Was für V3D Scan am wertvollsten ist

1. **Mesh Sketch Setup mit Offset-Pfeil und Live-Schnitt** (Basisebene wählen → Ebene ziehen/Wert
   tippen → pinke Schnittpolylinie): der Dreh- und Angelpunkt aller weiteren Schritte; bei uns ✗
   (Etappe 4). Die 2-mm-Erkenntnis (Schnitt nie genau in der Auflagefläche) gleich als Standard/
   Hinweis einbauen.
2. **Fit-per-Doppelklick mit Vor-Klassifizierung der Spur** (durchgezogen = Gerade, gepunktet =
   Bogen; Hover gelb): das eigentliche „Tracing“. Unsere Primitiv-Erkennung kann die Segmentierung
   der Polylinie liefern; Einzelklick-Mittelung zweier Segmente ist ein netter Zusatz.
3. **Plane/Vector aus Auswahl** mit Best Fit / Min. Bound / Max. Bound, N·Sigma-Ausreißerfilter und
   **Axis Constraint** (parallel/senkrecht zu vorhandener Ebene): macht unsere internen 3-2-1-Fits zu
   dauerhaften Referenzelementen im Baum; Zylinder-/Kegelachse haben wir faktisch schon.
4. **Disjoined Ends + Corner Trim**: kleiner Aufwand, aber Voraussetzung für extrudierbare,
   geschlossene Profile.
5. **Smart Dimension mit Doppelklick auf Nennmaß** (200.6214 → 200): passt direkt zu unserer
   vorhandenen Nennmaß-Rundung; Constraints-Dialog, der nur passende Bedingungen anbietet.
6. **Einheitliches Werkzeugfenster** (Preview/✓/✕/Restore, gelbes Aktiv-Feld, Vorauswahl) und
   **Edit über den Baum**: ein UI-Gerüst, das alle Etappen-4/6-Werkzeuge gleich bedienbar macht.
