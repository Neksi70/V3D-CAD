V3D Setup

Windows neu aufsetzen: Programme, Treiber, Updates

So geht's

1 · Alter Rechner
Starter laden und auf dem PC ausführen – er erscheint unten als Karte. Dort Inventar + Treiber sichern klicken.
2 · Hier abhaken
Links ankreuzen, was auf den neuen Rechner soll. Dann Auf V3DA herunterladen – die Installer liegen danach im Depot.
3 · Neuer Rechner
Nach der Windows-Installation denselben Starter ausführen und in seiner Karte Alles neu einrichten: Treiber zurück, Programme silent, Updates – auch über Neustarts.

⬇ Starter V3D-Setup.cmd  Windows warnt beim ersten Start (SmartScreen): „Weitere Informationen → Trotzdem ausführen“.
